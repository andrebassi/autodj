## Story

**As a** operador Premium,
**I want** tocar uma faixa Spotify importada dentro do browser (Web Playback SDK), com transição só por fade/TTS,
**so that** eu escute/prévia o catálogo Spotify no estúdio — sem nunca deixar o áudio DRM cruzar pro bus local de mix/broadcast.

> **Contexto de escopo.** Depende de 6.1 (token) e 6.2 (faixa importada). SDK do Spotify roda **só no browser**, exige Premium, e é um device separado. Two-engine: esse player é **isolado** do grafo Web Audio local (não há PCM p/ somar/crossfadear); transição só `fade_tts`/`hard_cut` (volume↓ → voz → próxima↑). Nunca toca Icecast/playout.

## Acceptance Criteria

1. **Player isolado.** Hook `useSpotifyPlayer` carrega o Web Playback SDK (`https://sdk.scdn.co/spotify-player.js`), autentica com o token de 6.1 (`AccessToken` via `/spotify/status` ou endpoint token dedicado), cria um device "AutoDJ". Só ativa se `premium` (senão UI mostra "requer Premium").
2. **Play/pause/seek** de uma faixa `source=spotify` (por `SpotifyURI`) via SDK. Estado (tocando/posição) exposto pelo hook.
3. **Isolamento two-engine (INVIOLÁVEL).** O player Spotify **não** compartilha `AudioContext` com o deck/cartwall; não há nó Web Audio ligado a ele (DRM/EME não expõe PCM). Transição do auto-DJ (6.4) usa fade de *volume do SDK* + TTS, nunca crossfade PCM. Nenhum caminho envia áudio Spotify pro playout local nem pro Icecast.
4. **UI.** No `SpotifyPanel`/resultado: faixa importada Premium ganha botão ▶ que toca pelo SDK; badge "DRM — só prévia, não vai ao ar". Sem Premium → botão desabilitado com aviso.
5. `pnpm build` OK (SDK carregado client-side, tipado; sem quebrar SSR/export estático).

## Dev Notes

- **DRM = sem PCM (confirmado 2025-2026).** EME não expõe samples; impossível crossfade/beatmatch/relay. Por isso player isolado e transição só fade/TTS. Isso é o coração do split dois-motores — não relaxar.
- **Premium obrigatório** pelo SDK. Detectar via `Account.Premium()` (6.1). Sem Premium, prévia indisponível (a faixa ainda existe como metadado importado).
- **Client-only:** SDK só no browser. Carregar via `window.onSpotifyWebPlaybackSDKReady`; guard de `typeof window`. Não quebrar o static export do Next.
- Token: reusar `AccessToken()` do backend (auto-refresh) via endpoint dedicado; o SDK pede um `getOAuthToken(cb)` — cb busca do backend.

### Testing

- Manual/browser (SDK exige device real Premium). Automatizável: hook renderiza gated por premium (sem Premium → não instancia player). `pnpm build` verde. Sem teste Go novo (feature client-side); endpoint token coberto no gate httpapi se criado.
