## Story

**As a** desenvolvedor de domínio,
**I want** as entidades `Track` e `Playable`/`SourceKind` com a matriz de capacidade e a `PlayQueue`,
**so that** o split de dois motores fique gravado e enforçado no domínio, com cobertura 100%, antes de qualquer I/O.

## Acceptance Criteria

1. `shared.SourceKind` ∈ {`local`, `spotify`, `line_in`, `tts`} com `Valid()`; `shared.Capabilities(s)` retorna a matriz correta (local = tudo true; spotify = tudo false; line_in/tts = PCM+Crossfade+Mixable true, Beatmatch/Waveform/ECAD false).
2. `shared.AllowedTransitions`/`TransitionAllowed`: fontes com PCM permitem `crossfade`/`fade_tts`/`hard_cut`; fontes sem PCM (spotify) permitem só `fade_tts`/`hard_cut`.
3. `library.NewTrack(id, source, title, dur)` valida id/fonte/duração e **deriva** `PCMAvailable`/`Mixable` da matriz; `Validate()` re-checa invariantes estruturais (local/line_in exige `Path`; spotify exige `SpotifyURI`) e **re-deriva** as flags mesmo após mutação.
4. `playback.PlayQueue{Playout:true}.Enqueue` rejeita fonte não-mixável com `ErrNotMixable` e transição inválida com `ErrBadTransition`; `Peek`/`Next` em fila vazia retornam `ErrEmptyQueue`.
5. A invariante `spotify ⇒ mixable=false` é impossível de violar por um caller no domínio.
6. Cobertura dos pacotes `domain/*` = **100%**.

## Dev Notes

- `domain/shared/source.go` — `SourceLocal/SourceSpotify/SourceLineIn/SourceTTS`. `Capability{PCM, Crossfade, Beatmatch, Waveform, Mixable, ECAD}`. O map `capabilities` é a **fonte única de verdade**; `Capabilities` retorna zero-value (tudo false = safe default) para kind desconhecido. `AllowedTransitions` deriva de `Capabilities(s).Crossfade`. Comentário de topo do arquivo deixa explícito que o split é load-bearing, não um toggle de UI.
- `domain/library/track.go` — `Track` carrega `Source shared.SourceKind`, `Path`, `SpotifyURI`, `Duration`, `BPM`, `MusicalKey` (Camelot), `WaveformRef`, `PlayCount` e as **flags derivadas** `PCMAvailable`/`Mixable` (comentário: "do not set directly — use NewTrack"). Erros: `ErrEmptyID`, `ErrBadSource`, `ErrLocalNeedsPath`, `ErrSpotifyNeedsURI`, `ErrBadDuration`. `NewTrack` valida id≠""/fonte válida/dur>0 e seta as flags de `caps := shared.Capabilities(source)`. `Validate` re-checa estrutura por fonte e ao final **re-deriva** as flags — logo, mesmo que alguém faça `t.Mixable = true` num track spotify, `Validate` desfaz. `Analyzed() = PCMAvailable && BPM > 0`.
- `domain/playback/queue.go` — `Playable{TrackID, Source, Title, URI, Duration}`; `Mixable()` = `shared.Capabilities(p.Source).Mixable`. `PlayQueue{Playout bool, items []QueueItem}`. `Enqueue`: se `Playout && !p.Mixable()` → `ErrNotMixable`; se `!TransitionAllowed(p.Source, t)` → `ErrBadTransition`. `Peek`/`Next` → `ErrEmptyQueue` se vazio; `Items()` retorna cópia; `Clear()` zera. Este é o ponto onde a invariante é enforçada **na fronteira da fila** (a segunda das quatro camadas: domínio-Track, fila, engine, DB).

### Testing

`domain/shared/source_test.go`, `domain/library/track_test.go`, `domain/playback/queue_test.go` — testes table-driven puros (sem mocks externos; domínio não tem I/O). Cobrem: cada `SourceKind` × cada campo da `Capability`; cada `Transition` permitida/negada por fonte; cada erro sentinela de `NewTrack`/`Validate`; re-derivação de flags após mutação; `Enqueue` playout vs. não-playout, transição inválida; `Peek`/`Next`/`Clear` incluindo fila vazia. **Cobertura atingida: 100%** nos três pacotes `domain/*` (gate exige exatamente 100%).
