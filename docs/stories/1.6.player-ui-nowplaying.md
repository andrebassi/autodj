## Story

**As a** operador/ouvinte,
**I want** um Player web que mostre a faixa tocando agora e a fila ao vivo, com um botão "Próxima",
**so that** eu veja e controle a rádio pelo navegador em tempo real.

## Acceptance Criteria

1. A API REST expõe `GET /api/health`, `POST /api/library/scan`, `GET /api/library/tracks`, `POST /api/playback/load`, `POST /api/playback/next`, `GET /api/playback/nowplaying`, com CORS aberto para o dev server Next.
2. O WebSocket `/ws` envia um snapshot imediato na conexão e um a cada 2s, no shape `nowPlayingMsg{type, now_playing, queue[]}`.
3. O Player Next.js mostra "Tocando agora" (título + badge da fonte + duração), a fila e os botões "Carregar biblioteca" (`POST /api/playback/load`) e "Próxima" (`POST /api/playback/next`).
4. As atualizações chegam ao vivo por WebSocket; ao cair a conexão, a UI mostra "reconectando" e reconecta automaticamente.
5. Cobertura dos pacotes `adapters/driving/httpapi` e `adapters/driving/ws` ≥ 90%.

## Dev Notes

- `adapters/driving/httpapi/router.go` — `Router{lib, play, wsHandler}`, `New(lib, play, wsHandler)` monta o chi com `middleware.Recoverer` + `cors` (Allow-Origin `*`, métodos GET/POST/OPTIONS; responde 204 a OPTIONS). Rotas: `GET /api/health` (`{status:"ok", version:Version="0.1.0"}`), `POST /api/library/scan` (decodifica `{root}`, 400 se vazio, chama `lib.ScanFolder`, `{scanned:n}`), `GET /api/library/tracks` (`toTrackDTOs`), `POST /api/playback/load` (`{queued:n}`), `POST /api/playback/next` (`{ok:true}`), `GET /api/playback/nowplaying` (`nowPlayingDTO`), e `Handle("/ws", wsHandler)` se não-nil. Sem lógica de negócio — só traduz HTTP↔use case.
- `adapters/driving/httpapi/dto.go` — `trackDTO` inclui `mixable`/`pcm_available` para o frontend **gatear features PCM-only** (crossfade/beatmatch/waveform) pela matriz. `playableDTO{track_id, title, source, duration_ms}`, `queueItemDTO{playable, transition}`, `nowPlayingMsg{type, now_playing, queue[]}` — o **shape único** que o Player consome, tanto no endpoint `nowplaying` quanto no WS.
- `adapters/driving/ws/hub.go` — `Hub{play, interval, conns}`; `NewHub(play, interval)` (default 2s se ≤0). `Run(ctx)` faz tick por `time.Ticker` e `broadcast` (poll `play.NowPlaying`, `json.Marshal(snapshot(...))`, escreve em cada conn com timeout 2s, dropa em erro). `ServeHTTP` faz `websocket.Accept` (`InsecureSkipVerify` para dev cross-origin), adiciona a conn, **envia um snapshot imediato** para a UI não ficar em branco, e bloqueia lendo até o client desconectar (server-push apenas). `ws/dto.go` tem seu próprio `snapshot` produzindo o mesmo `nowPlayingMsg{type:"nowplaying", ...}`.
- `web/app/page.tsx` — `Player` (`"use client"`). Estado: `snap: NowPlaying|null`, `connected`, `busy`. **WS reconnect loop** num `useEffect`: `connect()` abre `new WebSocket(wsURL())`; `onopen`→`connected=true`; `onclose`→`connected=false` + `setTimeout(connect, 1500)`; `onerror`→`ws.close()`; `onmessage`→`setSnap(JSON.parse(e.data))`; cleanup fecha o socket. **apiBase logic**: usa `NEXT_PUBLIC_API_BASE` se setado; senão, se `window.location.port === "3000"` (dev) → `http://localhost:8095`; senão mesmo origin (export servido pelo Go). `wsURL()` troca `http`→`ws` e adiciona `/ws`. UI: header com logo "AutoDJ" + indicador "ao vivo"/"reconectando" (dot verde/vermelho); card "Tocando agora" (título ou "— silêncio —", badge da `source`, duração `fmt(ms)`); botões "Carregar biblioteca" (`post("/api/playback/load")`) e "Próxima ▸" (`post("/api/playback/next")`, desabilitado sem now-playing); card "Fila (n)" listando índice/título/badge de transição. Textos user-facing em pt-BR.
- `web/app/globals.css` — tema escuro (vars `--bg`, `--panel`, `--accent` verde `#17c964` etc.), cards arredondados, badges, botão primário — **base do design system** para os próximos épicos. `web/next.config.mjs`: `output:"export"`, `images.unoptimized` → `web/out`.
- `cmd/server/main.go` — sobe `ws.NewHub(playSvc, 2*time.Second)` em goroutine (`go hub.Run(ctx)`), monta `httpapi.New(libSvc, playSvc, hub)`, e serve: `/api/` e `/ws` pela API e `/` por `staticUI` (`web/out` via `WEB_DIR` se existir, senão cai na API — dev roda o Next à parte). `PORT` default 8095.

### Testing
