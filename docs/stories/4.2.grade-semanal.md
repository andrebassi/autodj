## Story

**As a** operador da rádio caseira,
**I want** montar a grade semanal atribuindo um *clock* (4.1) a cada célula (dia-da-semana × hora) e que a grade persista,
**so that** o scheduler saiba qual molde de hora usar em cada momento da semana, e o histograma de carga por hora (`GradeLoad`) reflita a grade real em vez do mock.

> **Contexto de escopo.** 4.1 entregou os moldes (clocks). 4.2 monta a **grade**: agregado `schedule.Grid` = mapa `(Weekday, Hour) → clockID` (7×24 = 168 células), célula vazia = sem programação. Esta story entrega a grade persistida + editor + a derivação real de `GradeLoad` (soma dos `ItemCount` dos clocks de cada hora do dia atual). A geração da playlist concreta continua sendo 4.3.

## Acceptance Criteria

1. **Agregado `schedule.Grid`.** Célula `Cell{Weekday time.Weekday, Hour int (0..23), ClockID string}`; `Grid{Cells []Cell}` (só células preenchidas). `Grid.Validate(known map[string]bool)`: `Hour` em `[0,23]`, `Weekday` em `[0,6]`, sem célula duplicada `(weekday,hour)`, todo `ClockID` referenciado existe em `known` (senão `ErrUnknownClock`). Sentinelas `ErrBadHour`, `ErrBadWeekday`, `ErrDuplicateCell`, `ErrUnknownClock`. `Grid.ClockAt(wd, hour) (string, bool)`. `schedule.DefaultGrid()` seed fictício. Domínio 100%.
2. **`schedule.HourlyLoad(g Grid, clocks map[string]Clock, wd time.Weekday) [24]int`** — para cada hora do dia `wd`, soma `ItemCount` do clock atribuído (0 se vazio). Pura, testável, domínio 100%.
3. **Porta `outbound.GridRepo`.** `Get(ctx) (schedule.Grid, error)` (single-row; grade vazia se nunca salvou), `Save(ctx, schedule.Grid) error`. Métodos no `TrackRepo`: `Grid()`.
4. **`ScheduleService` (parte 2).** `Grid(ctx) (schedule.Grid, error)`; `SaveGrid(ctx, schedule.Grid) (schedule.Grid, error)` valida contra os clocks conhecidos (busca `Clocks()` para o `known`), persiste, relê. `ContentService.GradeLoad` passa a derivar de `HourlyLoad(grid, clocks, hoje)` — mock só como fallback quando a grade está vazia.
5. **API REST.** `GET /api/v1/grid` → `Grid`; `PUT /api/v1/grid` recebe `Grid` JSON, valida/persiste, devolve. Validação → 422 (inclui `ErrUnknownClock`), body ruim → 400.
6. **Frontend.** `api.ts` `fetchGrid`/`saveGrid`; hook `useGrid`; `GradeModal` (grade 7×24, clique numa célula escolhe clock de um select alimentado por `useClocks`). Histograma do header passa a refletir a grade. Componente por arquivo.
7. Gate verde: domínio 100%, `app`/`httpapi`/`memory`/`sqlite`/`schedule` ≥90%; `pnpm build` OK.

## Dev Notes

- **Grid single-row** (uma grade da estação), JSON blob como `mix_settings`. Células vazias não são armazenadas.
- **`HourlyLoad` usa o dia corrente** via `Clock` (porta `outbound.Clock.Now()`) no app; o domínio recebe `wd` pronto (puro).
- **Validação cruzada** clock↔grid fica no app (busca clocks conhecidos), não no domínio da grade — o domínio só valida forma + recebe o set `known`.
- **Invariante dois-motores** intacto: grade referencia clocks (categorias PCM), nunca faixas Spotify.
