## Story

**As a** operador de rádio,
**I want** escanear uma pasta e popular a biblioteca com metadados extraídos dos arquivos,
**so that** eu tenha faixas locais mixáveis prontas para a fila.

## Acceptance Criteria

1. O `FolderScanner` percorre recursivamente `root` e retorna paths de arquivos de áudio (mp3, flac, wav, ogg, m4a, aac, opus, aiff), respeitando cancelamento de contexto.
2. O `MetadataExtractor` (ffprobe) extrai título/artista/álbum/duração/bitrate de um arquivo, com lookup de tag case-insensitive.
3. `app.LibraryService.ScanFolder(root)` faz upsert de `Track`s locais com `pcm_available=true`/`mixable=true`, id estável = `sha1(path)` (re-scan atualiza, não duplica), `Category="music"`; arquivos que falham extração/validação são pulados (best-effort).
4. `POST /api/library/scan {root}` retorna `{scanned:n}` e `GET /api/library/tracks` lista o catálogo com as flags de capacidade no DTO.
5. Cobertura dos pacotes `adapters/driven/library`, `adapters/driven/ffprobe` e `app` ≥ 90%.

## Dev Notes

- `ports/outbound/outbound.go` — `MetadataExtractor.Extract(ctx, path) (Metadata, error)`; `Metadata{Title, Artist, Album, Duration, Bitrate}`. `FolderScanner.Scan(ctx, root) ([]string, error)`. `TrackRepo{Upsert, List, Get, Count}`. Comentário reforça a direção `adapters → ports → domain` (o domínio nunca importa adapters).
- `adapters/driven/library/scanner.go` — `audioExts` map (`.mp3 .flac .wav .ogg .m4a .aac .opus .aiff`). `Scan` usa `filepath.WalkDir`; aborta em `ctx.Err()`; ignora diretórios; casa por `strings.ToLower(filepath.Ext(path))`. Ordem = ordem do WalkDir.
- `adapters/driven/ffprobe/ffprobe.go` — `Extractor{Bin}` (default `"ffprobe"`). `Extract` roda `ffprobe -v quiet -print_format json -show_format <path>`, faz `json.Unmarshal` em `probeOutput.Format{Duration, BitRate, Tags}`, mapeia via `tag(tags, key)` case-insensitive (`equalFold` próprio, sem alocar), converte `Duration` (segundos float → `time.Duration`) e `BitRate` (atoi). Mantido **out-of-process** para o servidor ficar cgo-free (`CGO_ENABLED=0`) — importante para o futuro Wails. O ffprobe vem na imagem de runtime.
- `app/library_service.go` — `ScanFolder`: `scanner.Scan` → para cada path `meta.Extract` (pula se erro) → `library.NewTrack(idFor(p), shared.SourceLocal, md.Title, md.Duration)` (pula se erro) → seta `Artist/Album/Path/Category="music"`, e `Title = p` se o título vier vazio → `t.Validate()` (pula se erro) → `repo.Upsert`. `idFor(path) = hex(sha1(path))` garante upsert idempotente em re-scan. `Tracks` = `repo.List`.
- `adapters/driven/memory/repo.go` — `TrackRepo` sob `map[string]*Track` + `sync.RWMutex`; `Upsert` chama `t.Validate()` (recusa track inválido) e guarda **cópia**; `List` retorna cópias ordenadas por ID; `Get` → `ErrNotFound`. Usado no walking skeleton, testes e desktop.

### Testing

- `app/services_test.go` + `app/services_error_test.go`: `ScanFolder` com scanner/extractor fakes (best-effort: pula extração/validação falha), `Tracks`.
