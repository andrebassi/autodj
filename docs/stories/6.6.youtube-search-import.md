## Story

**As a** operador,
**I want** buscar vídeos/playlists no YouTube e importá-los pra biblioteca como faixas `source=youtube` (metadados só),
**so that** eu use o catálogo YouTube no AutoDJ — pra estúdio/auto-DJ caseiro — sem nunca deixar o áudio não-PCM entrar no bus de mix.

> **Contexto de escopo.** Depende de 6.5 (token). Substitui o placeholder de busca do `YouTubePanel` por busca real via **YouTube Data API v3 com API KEY própria** (não o token OAuth). Import cria `Track{Source: SourceYouTube, YouTubeURI}` — a matriz já força `mixable=false`, `pcm_available=false`. Sem BPM/waveform/marker (não-PCM). Tocar no deck é 6.7. **Login Google segue obrigatório** (espelho fiel do Spotify): a aba fica gated atrás do "Conectar" de 6.5, mesmo a busca usando key.

## Acceptance Criteria

1. **Porta `YouTubeCatalog`** (outbound): `Search(ctx, q, kind) ([]CatalogItem, error)` (kind = video|playlist), `PlaylistItems(ctx, playlistID) ([]CatalogItem, error)`, `Videos(ctx, ids) ([]CatalogItem, error)` (durações). Adapter real fala com `www.googleapis.com/youtube/v3` usando a **API KEY** (`key=`), não o Bearer OAuth. Parsing testado com `httptest`. Durações ISO-8601 (`PT#M#S`) → ms; thumbnail (`snippet.thumbnails.medium.url`) → `ArtworkURL`.
2. **App**: `YouTubeService.Search(...)`, `ImportTracks(ctx, uris)` → cria `Track` via `NewTrack(youtubeID(uri), SourceYouTube, ...)` + `YouTubeURI`, persiste. Import de playlist = `PlaylistItems` + `Videos` (p/ durações) em lote. `youtubeID(uri)` = sha1 hex (igual `spotifyID`).
3. **REST**: `GET /api/v1/youtube/search?q&type` → itens; `POST /api/v1/youtube/import` (`{uris:[]}` ou `{playlistID}`) → faixas criadas (`source=youtube`). Sem conta conectada → 409; catálogo indisponível → 503.
4. **Invariante**: toda faixa importada nasce `mixable=false`/`pcm=false` (matriz garante). Endpoint de áudio já 403 pra youtube (não-PCM). Nada muda no bus de mix.
5. **UI**: `YouTubePanel.tsx` real — campo de busca chama `/search` (debounce 300ms, limit 10), resultados via API (sem lista hardcoded) com toggle video/playlist; botão importar chama `/import`; rows draggable com dataTransfer `text/autodj-youtube-uri` (+origin). Aba enxuta (só conexão + busca/import; lista de importadas oculta, padrão do Spotify v0.1.23). `OperacionalScreen` ganha categoria "youtube" e efeito de retorno OAuth lê `?op=youtube`. Hook `useYouTube` ganha `search`/`importItem`.
6. Gate verde: `app`/`httpapi`/`adapters/driven/youtube` ≥90%; `task web:build` OK.

## Dev Notes

- **Busca via API KEY, não OAuth.** `search.list` (custa ~100 unidades) e `videos.list`/`playlistItems.list` usam `key=<AUTODJ_YOUTUBE_API_KEY>`. O token OAuth de 6.5 serve só p/ identidade/gating (login obrigatório) — a Data API pública usa key. Quota ~10k/dia ≈ 100 buscas/dia → debounce 300ms + limit 10, sem polling de busca.
- **Durações num segundo request.** `search.list` NÃO devolve duração; buscar os ids em `videos.list?part=contentDetails` e parsear ISO-8601 `PT#M#S` → ms. Playlist idem via `playlistItems.list` (pega os videoIds) + `videos.list`.
- **Só metadados.** Import NÃO baixa áudio. Track guarda `YouTubeURI`; PCM/waveform/BPM vazios (não-PCM). `NewTrack` com `SourceYouTube` exige `YouTubeURI` (`ErrYouTubeNeedsURI`), já no domínio (6.5).
- **Thumbnail = ArtworkURL** (provider-agnóstico) → `/library/tracks/{id}/artwork` 302 redireciona, sem tocar em nada.
- Reusar o gating de conta de 6.5. Sem conta → erro claro na UI (a aba nem renderiza busca antes de conectar).
- **LIMITAÇÃO CONHECIDA — cota da busca (10k unidades/dia) + humanização de erro (v0.2.5).** Cota esgotada → upstream 429 (ou 403 c/ corpo `quotaExceeded`). Backend: `catalog.go` `isQuotaStatus` detecta e embrulha (`%w`) em `domain/youtube.ErrQuotaExceeded`; `httpapi/youtube.go` `writeYouTubeErr` mapeia p/ **HTTP 429** (não 500). Frontend: `lib/errors.ts` humaniza p/ pt-BR ("cota da busca esgotada — ~100 buscas/dia, reseta de madrugada; IMPORTE colando a URL"). **Eixos independentes**: busca precisa da **API key**, não do login OAuth; login só gateia a aba. Import por URL/ID (`videos.list` = 1 unidade) e playout **não** gastam cota. Aumentar cota: (a) importar por URL, (b) múltiplos projetos + round-robin de keys (não implementado — key única hoje), (c) audit oficial do Google (lento). Ver `docs/architecture.md` → "Limitações conhecidas" e `CLAUDE.md`.
