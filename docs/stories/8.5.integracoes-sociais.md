## Story

**As a** operador da rádio caseira,
**I want** anunciar nas redes (WhatsApp, X, Facebook) o que está tocando agora ou um recado curto, com um clique,
**so that** o público acompanhe a programação sem eu abrir cada rede na mão — e com a formatação/limite de caracteres já certos por plataforma.

> **Contexto de escopo.** Integração social é **metadado** (texto de post), nunca áudio — independente do invariante dos dois-motores (igual pedidos/8.3). O `domain/social` é **puro**: monta o texto do post por plataforma (limite de caracteres, hashtag, truncamento com reticências) a partir de uma data e de um resumo do "tocando agora". Publicar de verdade é um detalhe de adapter (`outbound.SocialGateway`): no uso caseiro entra um **stub** que devolve um recibo sintético (sem chamar API externa, sem credencial), e a troca por um gateway real (WhatsApp Cloud API / X / Graph) é só outro adapter — o domínio e o app não mudam. O "tocando agora" vem do `PlaybackService` (mesma fonte do site público 8.4); como `playback.Playable` não carrega artista, o anúncio usa **título + fonte**.

## Acceptance Criteria

1. **`domain/social` (puro, 100%).** `Platform string` com constantes `PlatformWhatsApp="whatsapp"`, `PlatformX="x"`, `PlatformFacebook="facebook"`; `Valid()`, `Label()` (WhatsApp/X/Facebook), `MaxLen()` (X=280, WhatsApp=65536, Facebook=63206) e `Platforms() []Platform` (lista canônica p/ a UI — sem lista hardcoded no front). Value objects `NowInfo{Title, Source string}`, `Post{Platform Platform; Text string; CreatedAt time.Time}`, `Receipt{Platform Platform; ExternalID, URL string; PublishedAt time.Time}`. `ComposeNowPlaying(p Platform, now NowInfo, createdAt time.Time) (Post, error)` monta "🎵 Agora na rádio: {título}" (+ hashtag no X), valida plataforma (`ErrBadPlatform`) e título não-vazio (`ErrNoTrack`), e **trunca por runes** ao `MaxLen()` com reticências. `ComposeCustom(p Platform, text string, createdAt time.Time) (Post, error)` apara/valida (`ErrEmptyText`) e trunca igual. Determinístico.
2. **Ports.** outbound `SocialGateway{ Publish(ctx, social.Post) (social.Receipt, error) }`. inbound `SocialService{ Platforms() []social.Platform; AnnounceNowPlaying(ctx, platforms []social.Platform) ([]social.Receipt, error); PostCustom(ctx, p social.Platform, text string) (social.Receipt, error) }`. `inbound.ErrNothingPlaying` quando não há faixa no ar para anunciar.
3. **App `SocialService`** — compõe `inbound.PlaybackService` (NowPlaying), `outbound.SocialGateway` e `Clock`. `AnnounceNowPlaying` lê o tocando-agora; nada no ar → `ErrNothingPlaying`; para cada plataforma monta o post (`ComposeNowPlaying`, `createdAt=clock.Now()`) e publica, coletando os recibos (falha de composição/gateway propaga, fail-fast). `PostCustom` monta+publica um post livre. `Platforms()` devolve `social.Platforms()`.
4. **Adapter driven `socialstub`** — `SocialGateway` caseiro: **não** chama rede externa, devolve `Receipt` sintético determinístico a partir do `Post` (`ExternalID` = `{plataforma}-{createdAt UnixNano}`, `URL` = `stub://{plataforma}/{ExternalID}`, `PublishedAt` = `post.CreatedAt`). Sem credencial, sem estado. No gate (≥90%).
5. **REST** (gated em `WithSocial`): `GET /api/v1/social/platforms` → lista `{key,label,max_len}`; `POST /api/v1/social/announce` body `{platforms:[...]}` → `{receipts:[...]}`; `POST /api/v1/social/post` body `{platform,text}` → recibo. Plataforma inválida/texto vazio → 422; nada tocando → 409. Serviço ausente → 404.
6. **UI**: painel "Redes sociais" — seleção de plataformas (da API), botão "Anunciar tocando agora", campo de recado livre + plataforma + "Publicar", e a lista de recibos retornados. Hook + componentes (1 por arquivo). Dados só da API.
7. Gate verde: `domain/social` 100%, `app`/`httpapi`/`socialstub` ≥90%; `pnpm build` OK.

## Dev Notes

- **Metadado, não áudio.** Nada aqui toca no bus de playout; sem `SourceKind`/`mixable`. O `NowInfo.Source` é só informativo (aparece implícito no texto se quisermos; nesta story o texto usa só título — fonte fica disponível p/ evolução).
- **Truncamento por runes.** `MaxLen()` conta runes, não bytes (emoji/acentos). Cortar em `max-1` runes + `…`.
- **Stub caseiro.** `socialstub` é o default do `cmd/server` (sempre wired) — uso pessoal não posta em rede real. Gateway real = outro adapter, sem mexer no domínio/app.
- **Fonte do tocando-agora.** `PlaybackService.NowPlaying` (mesma do 8.4). `Playable` sem artista → anúncio por título.
