## Story

**As a** operador logado,
**I want** salvar meu layout do player (painéis visíveis, ordem, tema, densidade),
**so that** cada pessoa tenha sua configuração ao logar, sem refazer toda vez.

> **Contexto de escopo.** Depende de 7.3 (RBAC — precisa de um usuário logado dono do layout). `domain/operatorprofile`. Preferências persistidas por usuário; o frontend lê no login e aplica.

## Acceptance Criteria

1. **`domain/operatorprofile` (puro, 100%).** `Profile{UserID, Theme, Density, Panels []PanelPref}` com `PanelPref{Key, Visible, Order}`. Validação: `Theme` ∈ {claro,escuro,auto} (`ErrBadTheme`), `Density` ∈ {compacto,confortavel} (`ErrBadDensity`), `Panels` sem chaves duplicadas (`ErrDupPanel`), ordem normalizada (0..n-1). `Default(userID)` monta o layout padrão. `Reorder`/`Toggle(key)` helpers.
2. **Porta `ProfileRepo`** (outbound): `Get(userID)`, `Upsert(Profile)`. Adapter SQLite/memory. Perfil ausente → `Default`.
3. **App `ProfileService`**: `Get(userID)` (default se ausente), `Save(Profile)` (valida via domínio, só o próprio usuário ou admin). Integra com `AuthService` (7.3) pra dono correto.
4. **REST/UI**: `GET /api/v1/profile/me`, `PUT /api/v1/profile/me`. O shell do player aplica tema/densidade/painéis do perfil; editor de layout (arrastar/ocultar painéis). Hook + componente (1 por arquivo).
5. Gate verde: `domain/operatorprofile` 100%, `app`/`httpapi` ≥90%; `pnpm build` OK.

## Dev Notes

- **Perfil por usuário** — usa o `UserID` do 7.3. Sem login (RBAC desativado) → perfil "anon" default (degradação graciosa).
- **Ordem normalizada:** `Reorder` reindexa 0..n-1; `Toggle` alterna visível. Chaves de painel = os painéis do shell (fila, biblioteca, cartwall, spotify, aidj, …).
- **Só o dono ou admin salva** — `Save` checa via AuthService; senão `ErrForbidden`.
- Tema/densidade são hints de CSS que o shell aplica (data-attrs).

### Testing

- Domínio: tema/densidade inválidos→erro; chaves duplicadas→`ErrDupPanel`; `Reorder` reindexa; `Toggle` alterna; `Default` cobre todos os painéis.
- `app`: get default se ausente; save valida + gate de dono; outro usuário→`ErrForbidden`.
- `httpapi`: me GET/PUT; validação→422; sem auth→perfil anon ou 401 conforme wiring.
