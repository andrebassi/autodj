## Story

**As a** operador,
**I want** buscar faixas/playlists no Spotify e importá-las pra biblioteca como faixas `source=spotify` (metadados só),
**so that** eu use o catálogo Spotify no AutoDJ — pra estúdio/auto-DJ falado — sem nunca deixar DRM entrar no bus de broadcast.

> **Contexto de escopo.** Depende de 6.1 (token). Substitui o mock `SpotifyPanel.tsx` (STUB hardcoded) por busca real. Import cria `Track{Source: SourceSpotify, SpotifyURI}` — a matriz já força `mixable=false`, `pcm_available=false`, `broadcast_allowed=false`. Sem BPM/waveform/marker (não-PCM). Tocar é 6.3.

## Acceptance Criteria

1. **Porta `SpotifyCatalog`** (outbound): `Search(ctx, token, q, kind) ([]CatalogItem, error)` (kind = track|playlist), `PlaylistTracks(ctx, token, playlistID) ([]CatalogItem, error)`. Adapter real fala com `api.spotify.com/v1` (integration-tier; parsing testado com `httptest`). `CatalogItem{URI, Title, Artist, DurationMs, Album}`.
2. **App**: `SpotifyService.Search(...)`, `ImportTrack(ctx, uri)` → cria `Track` via `NewTrack(id, SourceSpotify, ...)` + `SpotifyURI`, persiste no `TrackRepo`. Import de playlist = import em lote. Reusa o `AccessToken()` de 6.1 (refresh transparente).
3. **REST**: `GET /api/v1/spotify/search?q&type` → itens; `POST /api/v1/spotify/import` (`{uris:[]}` ou `{playlistID}`) → faixas criadas (`source=spotify`). Erro sem conta conectada → 409/401 mapeado.
4. **Invariante**: toda faixa importada nasce `mixable=false`/`pcm=false` (matriz garante). Endpoint de áudio (5.1) já 403 pra Spotify; cartwall (5.4) já rejeita. Nada muda no playout.
5. **UI**: `SpotifyPanel.tsx` real — campo de busca chama `/search`, resultados via API (sem lista hardcoded), botão importar chama `/import`; faixa importada aparece na biblioteca marcada Spotify/DRM (badge não-mixável). Hook `useSpotify` ganha `search`/`import`.
6. Gate verde: `app`/`httpapi`/`adapters/driven/spotify` ≥90%; `pnpm build` OK.

- **Só metadados.** Import NÃO baixa áudio (DRM). Track guarda `SpotifyURI`; PCM/waveform/BPM continuam vazios (não-PCM). `NewTrack` com `SourceSpotify` exige `SpotifyURI` (`ErrSpotifyNeedsURI`), já no domínio.
