## Story

**As a** ouvinte,
**I want** um stream Icecast tocável do áudio produzido pela rádio,
**so that** eu possa ouvir a AutoDJ em qualquer player.

## Acceptance Criteria

1. O Liquidsoap emite `output.icecast` no mount `/radio`; com a stack local de pé e a biblioteca carregada, `ffplay http://localhost:8000/radio` toca o stream.
2. O Icecast local sobe via `flake.nix` (`nix run .#services`) — **sem Docker** (regra global 23).
3. A imagem de deploy remoto (Fly.io) empacota Icecast + Liquidsoap + server num entrypoint único, na ordem **Icecast → Liquidsoap → migrate → server**, numa máquina 24/7.
4. `task broadcast:test` prova o stream (probe via ffprobe + instruções de play).

## Dev Notes

- **Local (Nix)** — `flake.nix` define o processo `icecast` no `process-compose."services"` com XML gerado por `pkgs.writeText`: `<listen-socket><port>8000</port>`, `<source-password>hackme</source-password>`, logdir `./.data/icecast/log`, basedir/webroot de `${pkgs.icecast}/share/icecast`. `readiness_probe.http_get` em `127.0.0.1:8000/`. Sobe com `nix run .#services` junto do Postgres. **Nenhum Docker no dev** (regra 23). O Liquidsoap (que faz `output.icecast` apontando para esse Icecast) é lançado à parte por `task engine:up` (`scripts/engine-up.sh` exporta `AUTODJ_ICECAST_HOST=localhost`, `AUTODJ_ICECAST_PASSWORD=hackme`).
- **Script de saída** — em `adapters/driven/liquidsoap/script.go`, o template termina com `output.icecast(%mp3(bitrate={{.Bitrate}}), host={{.IcecastHost}}, port={{.IcecastPort}}, password={{.IcecastPass}}, mount={{.Mount}}, name={{.StationName}}, radio)`. Default mount `/radio`, porta 8000, bitrate 128. Junto do `mksafe`, garante saída contínua.
- **Remoto (Fly.io — único lugar com Docker)** — `Dockerfile` multi-stage: (1) `node:22` builda o web (`pnpm build` → `web/out`); (2) `golang:1.26` builda `server`/`migrate`/`engine` com `GOWORK=off CGO_ENABLED=0`; (3) runtime `savonet/liquidsoap:v2.4.0` + `apt-get install icecast2 ffmpeg ca-certificates`. Copia binários para `/usr/local/bin`, `web/out` para `/app/web/out`, `migrations` e `deploy/entrypoint.sh`. Env: `PORT=8095`, `WEB_DIR=/app/web/out`, `AUTODJ_LS_SOCKET=/tmp/autodj/autodj.sock`, `AUTODJ_ICECAST_HOST=127.0.0.1`. Expõe 8095 e 8000.
- **entrypoint** — `deploy/entrypoint.sh` (`set -euo pipefail`): cria dirs; renderiza o `deploy/icecast.xml` substituindo `@SOURCE_PW@`/`@ADMIN_PW@` pela env `ICECAST_SOURCE_PASSWORD` (Fly secret); `icecast2 -c ...&`; exporta `AUTODJ_ICECAST_PASSWORD` e roda `engine /app/.data/liquidsoap/radio.liq` (render) + `liquidsoap ... &`; se `DATABASE_URL`, roda `migrate /app/migrations`; `exec server`. Ordem: **Icecast → Liquidsoap → migrate → server**, tudo numa máquina.
- **fly.toml** — `app="autodj"`, `primary_region="gru"`. `http_service` interno 8095, `force_https`, `auto_stop_machines="off"` (broadcast 24/7 nunca idle-stop), `min_machines_running=1`, health check `GET /api/health`. Bloco `services` TCP com `internal_port=8000` e porta pública 8000 (`proxy_proto`) + tcp_check — o stream Icecast. VM `shared-cpu-1x`/1gb.
- `scripts/broadcast-test.sh` — probe do `http://localhost:8000/radio` via `ffprobe` (se presente) e imprime a instrução `ffplay <url>`.
