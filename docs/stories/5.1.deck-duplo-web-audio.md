## Story

**As a** operador/DJ da rádio caseira,
**I want** dois decks de verdade no navegador (A e B) que carreguem faixas locais (PCM), toquem/pausem, mostrem o playhead ao vivo e cruzem entre si por um crossfader real,
**so that** eu possa mixar duas músicas à mão no browser — não só ver um mockup — mantendo o Spotify (DRM) fora do bus de mix.

> **Contexto de escopo.** Épico 5 abre aqui. Até 4.x os decks (`Deck.tsx`/`DeckPair.tsx`) eram mockup visual (`fakeWave`, `frac` fixo). 5.1 os torna **reais**: um `AudioContext` por página, cada deck com `BufferSource → GainNode`, um crossfader que soma os dois gains por curva equal-power. O backend ganha um endpoint que **serve os bytes PCM** de uma faixa mixável para o browser decodificar. Invariante dois-motores: só `Mixable && PCMAvailable` carrega — Spotify devolve 403, nunca vira `AudioBuffer`.

## Acceptance Criteria

1. **`domain/djdeck` (puro, 100%).** `Crossfade(pos float64) (gainA, gainB float64)` — curva equal-power (`pos` clamp [0,1]; `pos=0` → A cheio/B mudo, `pos=1` → inverso, `pos=0.5` → ~0.707/0.707, soma de potência ≈ 1). `Deck` state machine `Empty→Loaded→Cued→Playing→Paused→Ended` com transições válidas (`Load`, `Play`, `Pause`, `End`, `Eject`) e rejeição de transição inválida (`ErrBadTransition`). Nenhuma dep externa.
2. **Endpoint de áudio.** `GET /api/v1/library/tracks/{id}/audio` faz stream dos bytes do arquivo local com `Content-Type` por extensão, suporte a `Range` (seek), `Accept-Ranges: bytes`. **Só serve `Mixable && PCMAvailable`** → 403 `ErrNotMixable` para Spotify; 404 faixa inexistente; 404/500 arquivo sumido. Porta `outbound`: `TrackAudio(ctx, id) (io.ReadSeekCloser, meta, error)` ou reuso do `Storage`/path já existente.
3. **`useDeck` (hook).** Um `AudioContext` compartilhado (lazy, criado no 1º gesto do usuário); `load(trackId)` faz `fetch` do endpoint → `decodeAudioData` → guarda `AudioBuffer`; `play`/`pause`/`stop` via `AudioBufferSourceNode` recriado a cada play (Web Audio one-shot), `GainNode` por deck; expõe `state`, `position` (via `AudioContext.currentTime` - `startedAt`), `duration`. Recusa carregar faixa não-mixável (checa capability antes do fetch).
4. **`useDeckPair` (hook).** Orquestra deck A + B + `crossfade` (0..1) que aplica `djdeck.Crossfade` nos dois gains; `setCrossfade(pos)`. Carrega now/next da fonte compartilhada (mesma do header) como sugestão inicial, mas o operador pode trocar cada deck.
5. **UI real.** `Deck.tsx` mostra playhead ao vivo (do hook, não placeholder), botões Play/Pause/Cue/Eject, tempos reais (elapsed/remaining derivados de `position`/`duration`); `DeckPair.tsx` monta A+B + `Crossfader.tsx` (slider). Componente por arquivo; toda I/O via hook; sem lista hardcoded.
6. **Failover.** Backend offline → hook cai para estado vazio sem quebrar a UI (mesmo padrão de `useAutopilot`). Faixa não-mixável na UI → botão de carregar desabilitado com tooltip.
7. Gate verde: domínio 100% (`Crossfade` curva + clamp; `Deck` transições válidas/ inválidas), `app`/`httpapi` ≥90% (endpoint: mixável OK, spotify 403, 404, Range); `pnpm build` OK.

## Dev Notes

- **Curva equal-power** é a padrão de DJ (soma de *potência* constante, não de amplitude): `gainA = cos(pos·π/2)`, `gainB = sin(pos·π/2)`. Domínio testa os 3 pontos-âncora + monotonicidade + clamp fora de [0,1].
- **`Deck` state machine no domínio, grafo Web Audio no hook.** O domínio só valida transições (testável 100%); o hook faz o I/O de áudio (não testável em unit Go). `Deck` NÃO conhece Web Audio.
- **Endpoint de áudio = só bytes + Range.** Reusa o `path` do Track (já existe, `local/line_in`). Antes de abrir o arquivo, checa `Mixable && PCMAvailable` — é a 5ª superfície do invariante dois-motores (as 4 do CLAUDE.md continuam). Spotify não tem `path` → 403 explícito antes de tocar em disco.
- **Web Audio one-shot:** `AudioBufferSourceNode` só toca uma vez; pause/seek exigem recriar o node e rastrear offset. Guardar `AudioBuffer` decodificado; play cria node novo a partir do offset atual.
- **`AudioContext` só após gesto** (política de autoplay do browser): criar no 1º clique de Play/Load, não no mount.
- **Invariante dois-motores:** deck filtra `Mixable && PCMAvailable` no hook (antes do fetch) e no backend (antes de servir). Reaproveita capability matrix de `domain/shared`.

### Testing

- Domínio: `Crossfade` — pos 0 / 0.5 / 1, clamp <0 e >1, soma de potência ≈ 1; `Deck` — cada transição válida + rejeição de inválida (Play em Empty, Load em Playing conforme regra).
- `app`/`httpapi`: `audio` de faixa mixável → 200 + bytes; Spotify → 403; id inexistente → 404; `Range: bytes=0-99` → 206 + `Content-Range`.
