## Story

**As a** operador de rádio,
**I want** que a fila de playout seja empurrada para o Liquidsoap por socket Unix, com skip e crossfade,
**so that** o áudio local toque de fato, com transições suaves e sem nunca ficar em silêncio.

## Acceptance Criteria

1. O engine renderiza um script `.liq` contendo `request.queue`, `crossfade`, `mksafe`, `output.icecast` e o comando custom `autodj.nowplaying`.
2. `Push` empurra faixas mixáveis via socket (`radio_queue.push annotate:title=...:<uri>`, prefixando `file://` quando a URI não tem scheme); `Skip` faz `radio_queue.skip`; `NowPlaying` lê o título via `autodj.nowplaying`; `Healthy` responde a `version`.
3. `Push` recusa fonte não-mixável (spotify) com `ErrNotMixable`; crossfade é a transição default usada por `LoadFromLibrary`.
4. Quando o socket do Liquidsoap não responde, o servidor cai para o `stubengine` in-process (UI/WS funcionam, sem playout); o stub também recusa fontes não-mixáveis.
5. Cobertura dos pacotes `adapters/driven/liquidsoap`, `adapters/driven/stubengine` e `app` ≥ 90%.

## Dev Notes

- `adapters/driven/liquidsoap/script.go` — `ScriptConfig{SocketPath, QueueID, IcecastHost, IcecastPort, IcecastPass, Mount, StationName, Bitrate, CrossfadeSecs, EmergencyTrack}`. `DefaultScriptConfig`: socket `/tmp/autodj/autodj.sock`, queue `radio_queue`, host `icecast`, porta 8000, pass `hackme`, mount `/radio`, station `AutoDJ`, bitrate 128, crossfade 3.0s. `liqTemplate` (text/template) gera o grafo: `settings.server.socket` (habilita o socket Unix), `radio = request.queue(id=...)` (Go empurra faixas — **padrão AzuraCast**), `crossfade(duration=...)`, `mksafe(...)` (garante nunca-silêncio), um `on_metadata` que guarda `current_title` num `ref`, um `server.register` expondo `autodj.nowplaying` de volta ao Go, e `output.icecast(%mp3(bitrate=...), ...)`. `Render(cfg)` executa o template.
- `adapters/driven/liquidsoap/engine.go` — `Engine{cfg, lastURI}`. `WriteScript(path)` renderiza e grava o `.liq` (usado por `cmd/engine`/Taskfile antes do launch). `dial` abre o socket Unix com timeout 2s; `command` envia um comando telnet-style e lê linhas até `"END"`. `Push(item)`: **defesa em profundidade** — se `!item.Playable.Mixable()` → `ErrNotMixable`; monta a URI (`file://` se não tiver `://`), `annotate:title=%q:%s`, envia `radio_queue.push ...`, guarda `lastURI`. `Skip` → `radio_queue.skip`. `NowPlaying` → `autodj.nowplaying` (título) + espelho de `lastURI`, sempre `Source: SourceLocal`. `Healthy` → `version` responde sem erro. Comentário de topo: "Go é o cérebro de scheduling; Liquidsoap é o mixer/output — Go nunca reimplementa mixing".
- `adapters/driven/stubengine/stub.go` — `Engine{items, cur}` in-memory. `Push` recusa não-mixável (reusa `liquidsoap.ErrNotMixable`); se nada tocando, promove a faixa a now-playing, senão enfileira. `Skip` popa a próxima para now-playing. `NowPlaying` retorna `cur`. `Healthy` sempre true. É o que mantém a UI end-to-end viva sem Liquidsoap.
- `app/playback_service.go` — `PlaybackService{repo, engine, mu, queue}`, `queue = NewPlayQueue(true)` (bus de playout). `LoadFromLibrary`: `repo.List` → para cada `t.Mixable` → `queue.Enqueue(p, crossfade)` (pula se erro) → `engine.Push(QueueItem{p, crossfade})`. Faixas spotify são silenciosamente ignoradas pela invariante da fila. `Next`: `queue.Next()` (pop do espelho) + `engine.Skip`. `NowPlaying`: `engine.NowPlaying` + snapshot da fila. `toPlayable(t)` resolve `URI = Path` (ou `SpotifyURI` se spotify). Este é a **terceira camada** de enforcement (engine `Push` rejeita), somada a domínio e fila.
- `cmd/engine/main.go` — renderiza o `.liq` para um path (default `./.data/liquidsoap/radio.liq`), com overrides de env (`AUTODJ_LS_SOCKET`, `AUTODJ_ICECAST_HOST`, `AUTODJ_ICECAST_PASSWORD`). Go é dono do script; o Liquidsoap só executa. `scripts/engine-up.sh` roda `go run ./cmd/engine <script>` e então `exec liquidsoap <script>`.
- Wiring em `cmd/server/main.go`: `ls := liquidsoap.NewEngine(cfg)`; se `ls.Healthy(ctx)` usa Liquidsoap, senão `stubengine.New()` (log: "UI works, no playout").

Testa: `Render` contém o grafo esperado (`request.queue(id="radio_queue")`, `crossfade(`, `mksafe(`, `output.icecast`, `mount="/radio"`, `"nowplaying"`); `WriteScript` grava (cria dirs aninhados); `Push`/`Skip`/`NowPlaying`/`Healthy` contra o fake (confere `radio_queue.push ... file:///music/hit.mp3`, `radio_queue.skip`, título "Current Song", espelho de URI); `Push` recusa spotify com `ErrNotMixable`; socket ausente → `Healthy` false e todos os comandos erram; URI já com scheme não é re-prefixada com `file://`.

- `app/services_test.go`: `LoadFromLibrary` (só mixáveis, crossfade), `Next`, `NowPlaying`, `Queue` com engine fake.
