## Story

**As a** operador da rádio caseira,
**I want** ver a waveform de uma faixa PCM e arrastar/adicionar/remover os marcadores de cue (start/intro/refrão/carimbo/mixin/mixout/end) direto sobre a onda,
**so that** eu ajuste onde a música "entra"/"sai" visualmente e salve — enquanto Spotify (DRM, sem PCM) mostra o editor desabilitado porque não há onda nem marcadores.

> **Contexto de escopo.** Épico 3 = markers + editor waveform + mixagem fina. A 3.1 entregou o **modelo + persistência + API** dos marcadores (`PUT /library/tracks/{id}/markers`). Esta 3.2 entrega a **UI**: a waveform renderizada a partir de picos servidos pela API (`GET /library/tracks/{id}/waveform`) e o editor de marcadores arrastáveis que grava via a API da 3.1. Invariante dois-motores preservado: **waveform e marcadores só para PCM** — o endpoint recusa não-PCM (`ErrWaveformNotPCM`) e o editor entra em modo desabilitado para Spotify. A geração de picos é um **placeholder determinístico** (adapter `waveform`) com a mesma forma de fio que o analyzer real (`audiowaveform` → peaks JSON) produzirá depois, então o contrato de UI já está estável.

## Acceptance Criteria

1. **Porta `WaveformGenerator` + adapter placeholder.** `outbound.WaveformGenerator.Peaks(ctx, *Track, bars) ([]float64, error)` devolve picos normalizados `[0,1]`. Adapter `adapters/driven/waveform.Placeholder` sintetiza os picos de forma **determinística** a partir do `Track.ID` (FNV-1a → mulberry32, envelope random-walk + picos esparsos), estável entre chamadas e igual no servidor. Coberto ≥90%.
2. **Serviço de aplicação `Waveform`.** `LibraryService.Waveform(ctx, id, bars) (WaveformData, error)`: busca a faixa (`ErrTrackNotFound` se ausente), recusa não-PCM com `library.ErrWaveformNotPCM` (invariante dois-motores), delega ao gerador e devolve `{DurationMs, Peaks}`. Sem gerador injetado → `ErrWaveformUnavailable` (mesmo padrão de `Upload`/`MediaStore`). Injeção via `SetWaveformGenerator` (sem quebrar as chamadas de `NewLibraryService`).
3. **API REST.** `GET /api/v1/library/tracks/{id}/waveform?bars=N` devolve `{duration_ms, peaks:[...]}`; `bars` default 120, limitado a `[16, 2000]`. Erros: não-encontrado→404, não-PCM→422, sem gerador→500.
4. **Catálogo de kinds de marcador via API (kinds do domínio).** `content.OperationalCatalog().Markers` usa **as chaves reais do domínio** (`start`/`intro`/`hook`/`stamp`/`mixin`/`mixout`/`end`) com rótulo pt-BR + cor/ícone (apresentação). O editor lê essa paleta da API (`/ui/operational`) — nada hardcoded — então cada botão gera um marcador que **valida** no `PUT /markers` da 3.1.
5. **Editor de waveform (UI, componentizado).** `MarkersEditor` reescrito: carrega os marcadores reais da faixa (do `trackDTO`), busca os picos da API, renderiza a onda + réguas de marcador posicionadas por `posMs/durationMs`. Operador **adiciona** marcador (botão da paleta; kinds singleton substituem o existente), **arrasta** a régua para reposicionar (clamp `[0,duração]`), **remove** e **salva** (`PUT /markers`). Erro de validação (422) exibido; sucesso recarrega a biblioteca. Faixa não-PCM (Spotify) → editor em modo desabilitado ("sem waveform: DRM"). Regra Frontend INVIOLÁVEL: 1 componente por arquivo, dados/hook via API (`lib/api.ts` + `hooks/`), nada hardcoded.
6. `GOWORK=off go test ./... -cover` verde: domínio 100%, `app`/`httpapi`/`waveform` ≥90%. Gate `./scripts/coverage-gate.sh` passa. `pnpm build` do `web/` compila.

## Dev Notes

- **Por que porta + adapter placeholder (e não gerar no domínio).** Gerar picos é I/O de análise (o real é `audiowaveform` out-of-process), não regra de negócio. Modela-se como a porta `WaveformGenerator` do plano; hoje o adapter é um placeholder determinístico, amanhã lê o peaks JSON do analyzer — a app e a UI não mudam. A **regra** de domínio (waveform só PCM) fica no `ErrWaveformNotPCM` checado na app antes de delegar, coerente com `SetMarkers`/`ErrMarkersNotPCM` da 3.1.
- **Determinismo.** Os picos derivam do `Track.ID` (hash FNV-1a → PRNG mulberry32), então a onda é estável entre reloads e idêntica servidor/cliente — não "pisca". A porta recebe o `*Track` inteiro para, no futuro, usar `WaveformRef`/duração reais.
- **Kinds do domínio na paleta.** A paleta antiga do `content` usava chaves de UI (`refini`/`reffim`/`carimbo`) que **não** batiam com `MarkerKind`. Corrigido para as 7 chaves reais (`start`/`intro`/`hook`/`stamp`/`mixin`/`mixout`/`end`) com rótulo/cor pt-BR — assim o botão da paleta produz um marcador que passa no `PUT /markers`. Um teste de paridade guarda contra drift (toda chave da paleta é um `MarkerKind.Valid()`).
- **Singleton no editor.** `start`/`end`/`intro`/`mixin`/`mixout` são únicos: adicionar de novo **substitui** a posição (o domínio rejeitaria duplicata com `ErrDuplicateMarker`). `stamp`/`hook` acumulam. O domínio continua sendo a autoridade — o editor só evita o erro óbvio; se o operador burlar, o 422 aparece.
- **Marcadores viajam no `trackDTO`.** O editor não faz GET individual: os marcadores já vêm na lista (`/library/tracks`), então o `OpMedia` ganha `durationMs`/`pcm`/`cues` e o editor abre com o estado real. Só a waveform é buscada sob demanda (`useWaveform`), porque picos são payload maior e só interessam com o editor aberto.
- **Não-PCM (Spotify).** O endpoint de waveform devolve 422 e o editor detecta `pcm=false` e entra em modo desabilitado, sem sequer chamar a API — mesma matriz de capacidade da 3.1. Marcadores/onda nunca existem para DRM.
- **Bars limitado.** `[16,2000]` evita payload absurdo; 120 é o default (densidade de tela). O front pede a densidade que vai desenhar.

### Testing

- **Waveform (adapter)**: mesmo id → mesmos picos (determinismo); todos em `[0,1]`; `bars<=0` cai no default (120); `bars=N` devolve N valores.
- **App (`Waveform`)**: faixa PCM → picos + duração; id inexistente → `ErrTrackNotFound`; faixa Spotify → `ErrWaveformNotPCM`; sem gerador → `ErrWaveformUnavailable`.
- **HTTP**: `GET .../waveform` 200 com `{duration_ms,peaks}`; `bars` respeitado e clampado; id inexistente → 404; Spotify → 422.
- **Content**: toda chave de `Markers` é um `MarkerKind` válido (paridade paleta × domínio).
- **Frontend**: `pnpm build` compila; editor abre com marcadores reais, arrasta/add/remove/salva; Spotify desabilita.
