## Story

**As a** engenheiro de plataforma,
**I want** um esqueleto hexagonal Go com a stack local em Nix (sem Docker) e CI com gate de cobertura,
**so that** todo o trabalho subsequente parta de uma base reprodutível e as invariantes de qualidade sejam enforçadas desde o dia zero.

## Acceptance Criteria

1. O módulo Go é **local** (`module autodj`, Go 1.26.0); os imports usam o formato `autodj/domain/shared` etc.
2. A árvore hexagonal existe: `domain/`, `ports/{inbound,outbound}`, `adapters/{driven,driving}`, `app/`, `cmd/{server,migrate,engine}`, `migrations/`, `web/`, `deploy/`, `scripts/`, `docs/`.
3. `nix run .#services` sobe a stack local (Postgres 17 + Icecast) via `process-compose-flake`/`services-flake` — **sem Docker** (regra global 23).
4. `nix develop` provê o toolchain (go, node, pnpm, liquidsoap, icecast, ffmpeg, postgres, go-task).
5. `task -l` lista as tasks (Taskfile com `up`, `shell`, `engine:up`, `broadcast:test`, `test`, `cover`, `build`, `migrate`, `dev`, `lib:scan`, `playback:load`, `web:dev`, `web:build`, `deploy`).
6. CI roda `go vet`, `go test -cover` e `scripts/coverage-gate.sh` (domain 100%, adapters ≥90%); o job web faz `pnpm build`.
7. Docs AIOX existem em `docs/` (`prd.md`, `architecture.md`, `stories/`).

## Dev Notes

Arquivos e símbolos-chave:

- `go.mod`: `module autodj`, `go 1.26.0`. Deps diretas: `github.com/coder/websocket v1.8.15`, `github.com/go-chi/chi/v5 v5.3.1`, `github.com/jackc/pgx/v5 v5.10.0`. **Regra inviolável**: nome do módulo é `autodj` (nunca `github.com/...`); imports internos são `autodj/domain/...`, `autodj/ports/...`, etc.
- `flake.nix`: `inputs` = nixpkgs unstable, flake-parts, process-compose-flake, services-flake. `process-compose."services"` habilita `services.postgres."pg"` (`postgresql_17`, db `autodj`, `127.0.0.1:5432`) e um processo `icecast` (`${pkgs.icecast}/bin/icecast -c ${icecastXml}` com `readiness_probe.http_get` na 8000). O XML do Icecast é gerado inline por `pkgs.writeText` (source-password `hackme`, porta 8000, logdir `./.data/icecast/log`). **O Liquidsoap NÃO é iniciado pelo flake** — o Go/`task engine:up` é dono do ciclo de vida dele; o flake só coloca o binário no PATH via devShell. `devShells.default` = `go_1_23` (comentário: bump p/ 1.26 quando cair no nixpkgs; `go.mod` pina o toolchain), `nodejs_22`, `pnpm`, `liquidsoap`, `icecast`, `ffmpeg`, `postgresql_17`, `go-task`.
- `Taskfile.yaml`: `version: "3"`, `env: GOWORK: "off"` (o módulo builda standalone; o `go.work` do workspace é opcional). Tasks relevantes: `up` (`nix run .#services`), `shell` (`nix develop`), `engine:up` (`scripts/engine-up.sh`), `broadcast:test` (`scripts/broadcast-test.sh`), `test`, `cover`, `build` (server/migrate/engine em `bin/`), `migrate`, `dev` (`go run ./cmd/server`, `PORT` default 8095), `lib:scan` (curl POST scan, requer `FOLDER`), `playback:load`, `web:dev`/`web:build` (dir `web`, pnpm), `deploy` (`fly deploy`).
- `.github/workflows/ci.yml`: `on push [main,develop] + pull_request`. Job `go` (`GOWORK=off`): checkout, setup-go `1.26.0`, instala ffmpeg (para os testes do ffprobe), `go vet ./...`, `go test ./... -cover -count=1`, `./scripts/coverage-gate.sh`. Job `web`: pnpm/action-setup v9, setup-node 22 cache pnpm, `pnpm install --no-frozen-lockfile`, `pnpm build`.
- `scripts/coverage-gate.sh`: parseia a saída de `go test ./... -cover`, extrai o pkg `autodj/...` e a `coverage: N%`; `EXCLUDE_RE='autodj/(cmd/|adapters/driven/postgres)'` (integration-tier); `domain/*` exige `min=100.0`, o resto `90.0`; falha o build se algum pkot ficar abaixo.
- `Dockerfile` + `fly.toml`: **deploy remoto apenas** (regra 23 — Docker nunca para dev local). Detalhado na story 1.5.
