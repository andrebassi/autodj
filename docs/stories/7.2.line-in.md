## Story

**As a** operador,
**I want** armar uma entrada line-in (mic/aux/soundcard) como fonte PCM mixável no bus local,
**so that** eu fale ao vivo (talk-over) ou toque uma fonte externa por cima/entre as faixas — no uso caseiro.

> **Contexto de escopo.** Depende do playout (Épico 1). Line-in é `SourceLineIn` — já na matriz: PCM=true, Mixable=true, Beatmatch=false, ECAD=false. No Liquidsoap vira um `input.*` (harbor/alsa) somado ao bus com ducking. O domínio modela o *arm/level/duck*; o adapter comanda o Liquidsoap. Nada de DRM: só PCM real.

## Acceptance Criteria

1. **`domain/linein` (puro, 100%).** `Input{ID, Label, Armed, Gain float64, Duck float64}` com validação: `Gain`/`Duck` em [0,1] (`ErrBadLevel`), `Label` não-vazio (`ErrEmptyLabel`). `Arm()/Disarm()`, `SetGain`, `SetDuck`. `NewInput(id,label)` default disarmed, gain 1.0, duck 0.6. Fonte é sempre `shared.SourceLineIn` (PCM, mixável) — nunca beatmatch/waveform.
2. **Porta `LineInController`** (outbound): `Arm(ctx, Input) error`, `Disarm(ctx, id) error`, `SetLevels(ctx, Input) error`. Adapter Liquidsoap (socket) integration-tier; adapter `noop`/`memory` p/ teste/stub.
3. **App `LineInService`**: `List`, `Arm(id)`, `Disarm(id)`, `SetGain(id,v)`, `SetDuck(id,v)` — valida via domínio, comanda o controller, guarda estado. Só uma armada por vez? Não — permite múltiplas, mas cada arm empurra ao controller.
4. **Line-in é PCM/mixável** (matriz) — entra no bus local normal, faz ducking da música sob a voz. Nunca marcada como beatmatch/waveform/ECAD. Invariante dois-motores: Spotify continua `mixable=false`; line-in é a fonte PCM viva legítima.
5. **REST/UI**: `GET /api/v1/linein`, `POST /api/v1/linein/{id}/arm`, `POST .../disarm`, `PUT .../levels`. Painel line-in: botão arm/disarm + sliders gain/duck + indicador. Hook + componente (1 por arquivo).
6. Gate verde: `domain/linein` 100%, `app`/`httpapi` ≥90%; `pnpm build` OK.

## Dev Notes

- **Line-in = `SourceLineIn` = PCM mixável.** Talk-over caseiro: arma a captura, faz duck da música (baixa ganho da música sob a voz) e some no bus. Beatmatch/waveform não se aplicam (matriz já bloqueia).
- **Ducking:** `Duck` = quanto abaixar a música (0.6 = -40%) enquanto o line-in está armado. O Liquidsoap faz via `amplify`/`smooth_add`.
- **Múltiplas entradas** possíveis (mic + aux), cada uma com gain/duck próprios; o controller empurra por id.
- Sem áudio DRM aqui — é a fonte PCM viva. Não confundir com Spotify.

### Testing

- Domínio: gain/duck fora de [0,1]→`ErrBadLevel`; label vazio→`ErrEmptyLabel`; arm/disarm alternam `Armed`; defaults corretos.
- `app`: arm comanda controller fake + guarda estado; setLevels valida e empurra; disarm idempotente.
- `httpapi`: arm/disarm/levels; validação→422; rotas ausentes sem `WithLineIn`→404.
