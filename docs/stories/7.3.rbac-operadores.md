## Story

**As a** dono da estação,
**I want** login com papéis (admin/operador/locutor) e uma matriz de permissões,
**so that** cada pessoa só acesse o que seu papel permite (locutor não mexe na grade; operador não apaga biblioteca) — mesmo no uso caseiro multiusuário.

> **Contexto de escopo.** `domain/identity`. Uso caseiro = poucos usuários; persistência local = SQLite por instalação (não por usuário aqui — a lista de contas é global à estação). Senha via argon2id. Sessão JWT curta. A matriz papel→permissão é domínio puro.

## Acceptance Criteria

1. **`domain/identity` (puro, 100%).** `Role` (admin|operador|locutor), `Permission` (enum: library.write, schedule.write, playback.control, cartwall.fire, reports.read, users.manage, …), `User{ID, Name, Role, PassHash}`. `Can(role, perm) bool` a partir de uma matriz fixa. `NewUser` valida nome não-vazio (`ErrEmptyName`), role válida (`ErrBadRole`). Verificação de senha é porta (hash fora do domínio).
2. **Portas**: outbound `PasswordHasher{Hash(pw) (string,error); Verify(pw, hash) bool}` (adapter argon2id) + `UserRepo{Get, GetByName, List, Upsert, Delete}`; outbound `TokenIssuer{Issue(User) (string,error); Parse(token) (Claims,error)}` (adapter JWT). Inbound `AuthService{Login(name,pw) (token,User,error); Authorize(token, perm) (User,error); Users CRUD (só admin)}`.
3. **App `AuthService`**: `Login` (GetByName → Verify → Issue; falha → `ErrBadCredentials`), `Authorize` (Parse → `Can(role,perm)`; senão `ErrForbidden`), CRUD de usuários gated a `users.manage`. Seed de um admin default no boot se repo vazio.
4. **Middleware httpapi**: `RequireAuth`/`RequirePerm(perm)` — extrai Bearer, `Authorize`, injeta user no contexto; falta/inválido→401, sem permissão→403. Aplicado seletivamente às rotas mutáveis.
5. **REST/UI**: `POST /api/v1/auth/login`, `GET /api/v1/auth/me`, users CRUD sob `users.manage`. Tela de login + guarda no frontend (token em memória/localStorage), badge do usuário/papel. Hook + componentes (1 por arquivo).
6. Gate verde: `domain/identity` 100%, `app`/`httpapi` ≥90% (`argon2id`/`jwt` adapters integration-tier se necessário); `pnpm build` OK.

## Dev Notes

- **Matriz papel→permissão é o coração** — domínio puro, table-driven test cobre cada célula. admin=tudo; operador=playback/cartwall/reports; locutor=playback.control+cartwall.fire (sem library/schedule write).
- **Senha nunca no domínio:** `User.PassHash` é opaco; hash/verify via porta (argon2id). Nunca logar/echoar senha.
- **JWT curto** (ex. 8h) + claims {sub, role}. `Parse` valida assinatura/exp.
- **Seed admin** só se repo vazio (primeiro boot) — credencial via env, nunca hardcoded.
- Uso caseiro: SQLite global da estação guarda usuários; sem servidor externo.

### Testing

- Domínio: `Can` para cada (role,perm); `NewUser` valida nome/role; roles desconhecidas→`ErrBadRole`.
- `app`: login OK/senha errada→`ErrBadCredentials`; `Authorize` com/sem permissão→`ErrForbidden`; CRUD gated.
- adapters: argon2id hash≠plaintext e verify true/false; jwt round-trip issue→parse, token adulterado→erro.
- `httpapi`: middleware 401 sem token, 403 sem permissão, 200 com; login devolve token.
